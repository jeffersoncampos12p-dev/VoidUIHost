VoidUI Documentation

Welcome to the VoidUI documentation. VoidUI is a complete, modular, and elegant UI library for Lua/LuaU, designed to be one of the most modern and complete UI libraries available. This documentation covers everything from installation to advanced usage patterns.

Installation

VoidUI can be loaded using a loadstring call that fetches the library from a hosted source, or by requiring a local copy of the source files. The simplest approach is to use the loadstring method:

local VoidUI = loadstring(game:HttpGet(URL))()

For local installations, place the entire src directory into your project and require the main loader file:

local VoidUI = require(script.Parent.src.VoidUI)

Quick Start

After loading the library, you can create a window, add tabs and sections, and populate them with components in just a few lines of code:

local VoidUI = loadstring(game:HttpGet(URL))()

local Window = VoidUI:CreateWindow({
    Title = "My Application",
    Subtitle = "Powered by VoidUI",
})

local Tab = Window:CreateTab("Settings", "rbxassetid://iconId")
local Section = Tab:CreateSection("Preferences")

Section:CreateToggle({
    Text = "Enable Animations",
    Default = true,
    Callback = function(value)
        VoidUI:ToggleAnimations(value)
    end,
})

Section:CreateButton({
    Text = "Save",
    Style = "Primary",
    Callback = function()
        VoidUI:NotifySuccess("Saved!", "Your settings have been saved.")
    end,
})

API Reference

The VoidUI global API provides access to all library functionality. Here are the most commonly used functions:

Theme Management

  • VoidUI:SetTheme(themeName) — Sets the active theme by name
  • VoidUI:GetTheme() — Returns the current theme table
  • VoidUI:GetThemeName() — Returns the current theme name
  • VoidUI:SetAccent(color) — Sets the accent color
  • VoidUI:ToggleTheme() — Toggles between Dark and Light
  • VoidUI:CreateTheme(name, data) — Registers a custom theme
  • VoidUI:ListThemes() — Lists all available themes

Window Management

  • VoidUI:CreateWindow(config) — Creates a new window
  • VoidUI:DestroyWindow(window) — Destroys a window
  • VoidUI:DestroyAll() — Destroys all windows
  • VoidUI:GetWindows() — Gets all windows
  • VoidUI:GetActiveWindow() — Gets the active window

Notifications

  • VoidUI:Notify(config) — Displays a notification
  • VoidUI:NotifyInfo(title, desc) — Info notification
  • VoidUI:NotifySuccess(title, desc) — Success notification
  • VoidUI:NotifyWarning(title, desc) — Warning notification
  • VoidUI:NotifyError(title, desc) — Error notification
  • VoidUI:ShowDialog(config) — Shows a modal dialog

Animation & Blur

  • VoidUI:ToggleAnimations(enabled) — Enable/disable animations
  • VoidUI:SetAnimationQuality(quality) — Set animation quality
  • VoidUI:SetAnimationSpeed(speed) — Set animation speed
  • VoidUI:EnableBlur() / DisableBlur() — Control blur effects
  • VoidUI:SetTransparency(value) — Set background transparency

i18n

  • VoidUI:SetLanguage(lang) — Set the active language
  • VoidUI:GetLanguage() — Get the current language
  • VoidUI:Translate(key) — Translate a key
  • VoidUI:GetAvailableLanguages() — List available languages

State & Plugins

  • VoidUI:Export() — Export application state
  • VoidUI:Import(state) — Import application state
  • VoidUI:RegisterPlugin(name, init) — Register a plugin
  • VoidUI:UnregisterPlugin(name) — Unregister a plugin
  • VoidUI:ListPlugins() — List all plugins

Components

VoidUI includes over 50 components organized into categories. Each component is created through factory methods on a Section object or via the standalone VoidUI:Create(type, config) function.

Creating Components

Components are typically created within a section using factory methods:

Section:CreateButton({ Text = "Click Me", Callback = function() end })
Section:CreateToggle({ Text = "Enable", Default = true, Callback = function(v) end })
Section:CreateSlider({ Text = "Volume", Min = 0, Max = 100, Default = 50 })
Section:CreateDropdown({ Text = "Theme", Options = VoidUI:ListThemes() })

Component Signals

Every component emits signals that you can connect to for more control:

local button = Section:CreateButton({ Text = "Save" })
button.OnClick:Connect(function()
    print("Button clicked!")
end)

Themes

VoidUI ships with six built-in themes: Dark, Light, Midnight, Sunset, Forest, and Cyber. You can switch themes at any time, create custom themes, and customize the accent color independently.

-- Switch theme
VoidUI:SetTheme("Midnight")

-- Set custom accent
VoidUI:SetAccent(Color3.fromRGB(255, 100, 150))

-- Create a custom theme
VoidUI:CreateTheme("Ocean", {
    Background = Color3.fromRGB(12, 28, 48),
    Text = Color3.fromRGB(210, 230, 250),
    Accent = Color3.fromRGB(0, 160, 220),
})
VoidUI:SetTheme("Ocean")

Events & Callbacks

VoidUI uses a signal-based event system. Signals can be connected with :Connect(callback), which returns a connection object. You can disconnect using :Disconnect().

local Core = VoidUI:GetCore()
local Signal = Core.Signal

local mySignal = Signal.new()
local conn = mySignal:Connect(function(value)
    print("Received:", value)
end)
mySignal:Fire("Hello!")  -- prints: Received: Hello!
conn:Disconnect()

The library also includes a Promise implementation for asynchronous operations:

local Promise = VoidUI:GetCore().Promise

Promise.new(function(resolve, reject)
    if success then resolve(result) else reject(err) end
end)
:Then(function(result) print("Success:", result) end)
:Catch(function(err) print("Error:", err) end)

Internationalization

VoidUI supports English (en-US), Portuguese (pt-BR), and Spanish (es-ES) out of the box. You can change the language at any time and add custom translations.

VoidUI:SetLanguage("pt-BR")
print(VoidUI:Translate("save_button"))

-- Add custom translations
local i18n = VoidUI:GetI18n()
i18n.AddTranslations({
    ["en-US"] = { app_title = "My App" },
    ["pt-BR"] = { app_title = "Meu App" },
})

Plugins & Extensions

The plugin system allows third-party extensions to register custom components, themes, and hooks:

VoidUI:RegisterPlugin("MyPlugin", function(api)
    api.RegisterComponent("MyWidget", function(config)
        return { Value = config.Default or 0 }
    end)
    api.On("ThemeChanged", function(name)
        api.Log("Theme: " .. name)
    end)
end)

Best Practices

Group related components together in sections for better organization. Use the Callback parameter for simple event handling and direct signal connections only when you need multiple listeners. Always disconnect connections you create and destroy components when they are no longer needed. Use the Export/Import system to persist user preferences between sessions.

Troubleshooting

If components are not showing, ensure you have created a window, tab, and section in the correct order. If themes are not applying, verify the theme was registered before setting it. For performance issues, try disabling animations with VoidUI:ToggleAnimations(false) or reducing the animation quality.

Migration Guide

Migrating from other UI libraries to VoidUI is straightforward. The window/tab/section pattern is similar across libraries. The main differences are in naming (VoidUI uses Text instead of Title for component labels) and the additional features VoidUI provides. See the full migration guide in the documentation for detailed mappings.
