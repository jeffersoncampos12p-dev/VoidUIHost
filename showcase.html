Component Categories

VoidUI components are organized into logical categories for easy navigation.

🏗️

Structural

Window, Tab, SubTab, Section, GroupBox — the building blocks of your interface hierarchy.

⌨️

Input

Button, Toggle, Checkbox, Slider, Dropdown, ColorPicker, Keybind, Textbox, and more for collecting user input.

💬

Feedback

Notification, Dialog, Modal, Tooltip, Badge, ProgressBar, LoadingScreen for communicating with users.

🖼️

Display

SplashScreen, WelcomeScreen, Card, Avatar, Image, VideoPreview, Divider, Spacer for presenting content.

📊

Complex Data

Accordion, TreeView, List, DataTable, StatusIndicator, Chip, Tag, Breadcrumb, Pagination for structured information.

🧭

Navigation

FloatingButton, Sidebar, Navbar, ContextMenu, RightClickMenu for application navigation patterns.

🪟

Window Management

WindowManager, DockingSystem, TabsReorder for managing multiple windows and their layout.

🖥️

Developer Tools

Toasts, CommandPalette, Terminal, Console, LogViewer for building developer-facing interfaces.

Visual Effects

The subtle details that make VoidUI interfaces feel premium and refined.

🌫️

Acrylic Blur

Blur effects behind windows create depth and a modern glass aesthetic.

💧

Ripple Effects

Material-style ripple animations on interactive elements with object pooling for performance.

✨

Glow Effects

Subtle glow on hover and focus states adds polish without being overwhelming.

📐

Smooth Tweens

Fluid transitions on every interaction using TweenService with configurable speed and quality.

🌈

Gradients

Subtle gradients on primary buttons, progress bars, and accents for visual depth.

⬜

Soft Borders

Rounded corners with subtle border colors create a refined, modern appearance.
