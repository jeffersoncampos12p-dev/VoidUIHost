## Credits

### VoidUI

VoidUI was designed and developed by the **NinjaTech AI Team**. The library was conceived with the goal of creating the most modern, elegant, and complete UI library for the Lua/LuaU scripting environment, drawing inspiration from contemporary design trends and modern UI frameworks.

### Inspirations

VoidUI was inspired by the organizational concepts of WindUI and other Lua UI libraries in the community. While the code, visual identity, architecture, and component implementations are entirely original, the general patterns of window/tab/section organization that have become standard in the Lua UI community informed the design of VoidUI's architecture.

The visual design draws inspiration from modern web and desktop UI frameworks, with their emphasis on clean lines, soft shadows, rounded corners, subtle animations, and restrained color palettes. The goal was to bring this level of polish and sophistication to the Lua scripting world.

### Technologies

VoidUI is built on the Lua/LuaU scripting language and the Roblox platform. It utilizes the following Roblox services and technologies:

- **TweenService** for smooth animations and transitions
- **RunService** for frame-based updates and animations
- **UserInputService** for keyboard and mouse input handling
- **HttpService** for JSON encoding and decoding
- **CoreGui and PlayerGui** for UI parent containers
- **Players** for player-specific UI management
- **Roblox Instance system** for creating all UI elements (Frame, TextButton, TextLabel, ImageLabel, ScrollingFrame, UICorner, UIStroke, UIGradient, UIPadding, UIListLayout, etc.)
