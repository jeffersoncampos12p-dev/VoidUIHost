Changelog

All versions of VoidUI — features, improvements, and bug fixes

v1.0.0 Latest Stable
2026-01-15

Initial release of VoidUI — the most modern, elegant, and complete UI library for Lua/LuaU. Built from the ground up with an original architecture, visual identity, and 50+ components.

✦ Added — Core Library

  • VoidCore module with Signal class, Promise implementation, Object base class, Utilities, Color utilities, and StateManager
  • ThemeSystem with 6 built-in themes: Dark, Light, Midnight, Sunset, Forest, and Cyber
  • AnimationSystem with tween helpers, ripple effect (object pooling), glow effect, hover/press/pulse/shake/spinner/bounce/sweep animations
  • EventSystem with global signal, keybind system, and event dispatcher
  • i18n system supporting Portuguese (pt-BR), English (en-US), and Spanish (es-ES)
  • PluginSystem with component registration, theme registration, lifecycle hooks, and full plugin utilities
  • StateManager for config persistence and state save/load
  • Main loader VoidUI.lua with complete global API

Added — Structural Components

  • Window with dragging, tab management, state persistence, minimize/maximize, and 40+ configuration options
  • Tab with icon, content area as ScrollingFrame, SetActive/Deactivate
  • SubTab for secondary navigation within Tabs
  • Section with Collapsible/Collapsed/Side options and factory methods for all components
  • GroupBox container with title, description, and border

Added — Input Components

  • Button with 5 styles (Primary, Secondary, Ghost, Danger, Success), icon, hover, ripple, press, and gradient
  • Toggle — iOS-style switch with label, description, smooth animations, OnChanged
  • Checkbox — square box with checkmark and smooth animations
  • Slider with Min/Max/Step, suffix/prefix, format, track, filled, gradient, knob, and drag
  • Dropdown with options list, searchable, icons, expand/collapse, outside click
  • MultiDropdown with multi-select checkboxes and clear all
  • ColorPicker with HSV color wheel, saturation/value area, hue slider, hex input
  • Keybind with live key capture, key formatting, trigger modes, OnTriggered/OnChanged
  • Textbox with label, placeholder, multiline, max length, numeric, focus/blur
  • Input — no label variant with icon support
  • PasswordInput with mask/unmask toggle (eye icon)
  • SearchBox with search icon, clear button, debounce, OnSearch/OnChanged
  • CodeEditor with monospace font, line numbers, and copy button

Added — Feedback Components

  • Notification — toast-style with 4 variants, auto-dismiss, close button, OnDismiss
  • Dialog — pre-built modal with title, message, configurable buttons, 4 variants
  • Modal with dimmed backdrop, custom content, backdrop close, OnOpen/OnClose
  • Tooltip with 4 positions, delay, SetTarget/SetText/SetEnabled
  • LoadingScreen — full-screen overlay with spinner, progress, brand logo
  • Badge with 5 variants (Default, Success, Warning, Error, Info), icon, pill
  • ProgressBar with Min/Max, label, value display, gradient fill animation, OnComplete

Added — Display Components

  • SplashScreen — branded splash with logo, brand name, tagline, gradient, pulsing dots
  • WelcomeScreen — multi-step onboarding with slides, progress dots, navigation
  • Avatar with image, initials fallback, 4 size variants, ring, status indicator
  • Image with rounded corners, border, caption, hover, click
  • VideoPreview with thumbnail, play icon, duration badge, pulsing play
  • Card with title, description, optional image, hover/press/ripple, OnClick
  • Divider — horizontal/vertical variants with optional text
  • Spacer — configurable size

✦ Added — Complex Components

  • Accordion — collapsible items with single/multiple open, icons, animations
  • TreeView — hierarchical nodes with expand/collapse, selection, nested indentation
  • List — scrollable, selectable items with icon/label/description
  • DataTable with columns, rows, sorting, selection, alternating rows
  • StatusIndicator with 6 statuses, optional text label, pulsing animation
  • Chip — interactive chip with selection state, icon, avatar, close
  • Tag — compact label, closable, 5 variants, icon
  • Breadcrumb — navigation trail with clickable items, separators, current page
  • Pagination with page numbers, prev/next, ellipsis

Added — Navigation Components

  • FloatingButton — FAB with 5 positions, extended variant, tooltip, pulsing glow
  • Sidebar — vertical nav with logo, items, footer, collapse/expand
  • Navbar — horizontal nav with title, links, action buttons
  • ContextMenu — position-based, icons, separators, disabled, danger, shortcuts
  • RightClickMenu — attaches ContextMenu on right-click

Added — Window Management

  • WindowManager — multi-window, focus management, z-ordering
  • DockingSystem with dock positions, dock zone indicators
  • TabsReorder — drag-to-reorder with LayoutOrder swap

Added — Developer Tooling

  • Toasts — singleton toast manager with Notify/Info/Success/Warning/Error
  • CommandPalette — VS Code-style with fuzzy search, keyboard nav, Ctrl+P
  • Terminal — terminal-style with command input, output, history
  • Console — dev console with log levels, filtering, export
  • LogViewer — syntax-highlighted log viewer with severity filtering, auto-scroll

Added — Global API

  • Core module access: GetCore, GetThemeSystem, GetAnimationSystem, GetEvents, GetI18n, GetPlugins
  • Theme API: SetTheme, GetTheme, GetThemeName, LoadTheme, SaveTheme, CreateTheme, ListThemes, SetAccent, ToggleTheme
  • Window API: CreateWindow, DestroyWindow, DestroyAll, GetWindows, GetActiveWindow
  • Notification API: Notify, NotifyInfo, NotifySuccess, NotifyWarning, NotifyError, ShowDialog
  • Toasts API: GetToasts, Toast
  • Loading/Splash API for full-screen overlays
  • i18n API: SetLanguage, GetLanguage, GetAvailableLanguages, Translate
  • Animation API: ToggleAnimations, SetAnimationSpeed
  • Blur API: EnableBlur, DisableBlur, SetTransparency
  • Component Factory: Create (universal component creation)
  • Command Palette API: OpenCommandPalette, CloseCommandPalette, ToggleCommandPalette
  • Debug Console API: OpenConsole, Log, Info, Warn, Error
  • Import/Export API for configurations
  • Version API: GetVersion, GetVersionInfo
  • Plugin API: RegisterPlugin, UnregisterPlugin, FireHook
  • Lifecycle hooks: FireHook("Init") at initialization

Added — Documentation

  • README with introduction, quick start, and architecture overview
  • Installation guide with 3 methods (loadstring, local script, model)
  • Getting started guide with step-by-step tutorial
  • Complete API reference with all functions documented
  • Components reference for all 50+ components
  • Themes documentation with 6 built-in themes and custom theme creation
  • Events & callbacks documentation (signals, promises, events)
  • i18n documentation
  • Plugin/extension documentation with full API
  • Examples collection with 10 complete examples
  • FAQ with 20+ questions
  • Migration guide from WindUI and other libraries
  • Best practices guide
  • Troubleshooting guide
  • License (MIT) and credits

Added — Website

  • Landing page with hero, interactive demo, features, component grid, theme gallery
  • Documentation page with sidebar navigation and full API docs
  • Showcase page with interactive demo and visual effects gallery
  • Playground with interactive code editor and live preview
  • Changelog page (this page)
  • FAQ page
