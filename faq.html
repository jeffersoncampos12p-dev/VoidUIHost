Frequently Asked Questions

Everything you need to know about VoidUI — installation, usage, components, and more.

General
What is VoidUI?

VoidUI is a modern, elegant, and complete UI library for Lua/LuaU, designed for building premium user interfaces in the Roblox environment. It features 50+ components, 6 built-in themes, 3 language packs, a full plugin system, and comprehensive documentation — all built from scratch with an original architecture and visual identity.

Unlike other libraries that wrap existing code, VoidUI was designed and built entirely from the ground up, with inspiration taken from WindUI's organizational concepts but with completely original code, visual design, and API.

Is VoidUI free to use?

Yes! VoidUI is open source and released under the MIT License. You are free to use it in personal and commercial projects, modify it, and distribute it. The only requirement is to include the original copyright notice and license text.

What Lua/LuaU versions are supported?

VoidUI is built for LuaU, the dialect of Lua used in Roblox. It leverages Roblox-specific services like TweenService, HttpService, UserInputService, and CoreGui. The library is compatible with all current Roblox executor environments.

How is VoidUI different from other UI libraries?

VoidUI stands out in several key areas:

  • Original codebase — built from scratch, not a wrapper around existing libraries
  • 50+ components — the most complete component set available
  • 6 built-in themes with full custom theme support
  • 3 languages built-in (pt-BR, en-US, es-ES)
  • Plugin system with hooks, custom components, and themes
  • Developer tools — Command Palette, Terminal, Console, LogViewer
  • Modern animations — ripple, glow, hover, press, pulse, and more
  • Comprehensive documentation — 16 documentation files and an official website
Where can I get the source code?

VoidUI is available on GitHub. You can clone the repository, download the latest release, or use the loadstring method for quick installation. See the documentation for detailed installation instructions.

Usage
How do I create my first window?

Creating a window is simple:

local VoidUI = loadstring(game:HttpGet(
    "https://voidui.dev/latest.lua"
))()

local Window = VoidUI:CreateWindow({
    Title = "My App",
    Theme = "Dark",
    Size = Vector2.new(580, 460),
})

local Tab = Window:AddTab({ Title = "Home" })
local Section = Tab:AddSection({ Title = "Settings" })
Section:AddButton({ Text = "Hello!", OnClick = function() end })

See the getting started guide for a complete walkthrough.

How do I change the theme?

You can change the theme at any time using the global API:

VoidUI:SetTheme("Light")  -- or "Dark", "Midnight", "Sunset", "Forest", "Cyber"

You can also create custom themes with VoidUI:CreateTheme() and save/load them with SaveTheme() and LoadTheme().

How do I handle events and callbacks?

VoidUI uses a Signal-based event system. Most components accept callback functions directly in their configuration:

Section:AddButton({
    Text = "Save",
    OnClick = function()
        print("Saved!")
    end,
})

Section:AddToggle({
    Text = "Enable feature",
    OnChanged = function(value)
        print("Feature enabled:", value)
    end,
})

You can also connect to signals manually using :Connect() for more control over event handling and disconnection.

How do I save and restore the UI state?

VoidUI includes a StateManager in the VoidCore module that handles config persistence. You can save the current state and load it later:

-- Save current state
VoidUI:Export("myConfig")

-- Load saved state
VoidUI:Import("myConfig")

Toggle and slider values, dropdown selections, and other component states are automatically persisted when configured.

Components
How many components does VoidUI have?

VoidUI includes 50+ components organized into 8 categories:

  • Structural: Window, Tab, SubTab, Section, GroupBox
  • Input: Button, Toggle, Checkbox, Slider, Dropdown, MultiDropdown, ColorPicker, Keybind, Textbox, Input, PasswordInput, SearchBox, CodeEditor
  • Feedback: Notification, Dialog, Modal, Tooltip, LoadingScreen, Badge, ProgressBar
  • Display: SplashScreen, WelcomeScreen, Avatar, Image, VideoPreview, Card, Divider, Spacer, Label, Paragraph
  • Complex: Accordion, TreeView, List, DataTable, StatusIndicator, Chip, Tag, Breadcrumb, Pagination
  • Navigation: FloatingButton, Sidebar, Navbar, ContextMenu, RightClickMenu
  • Window Management: WindowManager, DockingSystem, TabsReorder
  • Developer Tooling: Toasts, CommandPalette, Terminal, Console, LogViewer
Can I create custom components?

Yes! The Plugin System allows you to register custom components that integrate seamlessly with the rest of the library:

local Plugin = VoidUI:GetPlugins():Register("MyPlugin")
Plugin:RegisterComponent("MyWidget", function(config)
    -- Create your custom component here
    return {
        Instance = frame,
        SetValue = function(self, val) end,
        OnChanged = Signal.new(),
    }
end)

-- Then use it:
Section:AddMyWidget({ Title = "My Custom Widget" })
How do I use the ColorPicker?

The ColorPicker provides an HSV color wheel, saturation/value area, hue slider, and hex input:

Section:AddColorPicker({
    Text = "Accent Color",
    Default = Color3.fromRGB(120, 80, 255),
    OnChanged = function(color)
        print("Color:", color)
    end,
})

The OnChanged callback fires whenever the user selects a new color, passing the Color3 value.

How do I use the Keybind component?

The Keybind component allows users to set a keyboard shortcut by pressing a key. It supports trigger modes (OnPress, OnRelease, OnToggle):

Section:AddKeybind({
    Text = "Toggle UI",
    Default = Enum.KeyCode.RightShift,
    Mode = "Toggle",
    OnTriggered = function()
        print("Keybind triggered!")
    end,
    OnChanged = function(keyCode)
        print("Key changed to:", keyCode)
    end,
})
How do I show notifications?

VoidUI provides several notification methods:

VoidUI:Notify({
    Title = "Update Available",
    Description = "Version 2.0 is ready to install",
    Duration = 5,
})

VoidUI:NotifySuccess({ Title = "Saved!", Description = "Settings updated" })
VoidUI:NotifyWarning({ Title = "Warning", Description = "Low memory" })
VoidUI:NotifyError({ Title = "Error", Description = "Failed to connect" })

You can also use the Toasts system for stacked, dismissible notifications with VoidUI:Toast().

Performance
Is VoidUI performant?

Yes. VoidUI is built with performance in mind:

  • Object pooling for ripple effects and reusable UI elements
  • Efficient tweens using Roblox's TweenService with minimal overhead
  • Lazy initialization — components are only created when needed
  • Auto-disconnect — signals clean up automatically to prevent memory leaks
  • Debounced inputs — search boxes and text inputs use debouncing to reduce callback frequency

You can also toggle animations off with VoidUI:ToggleAnimations(false) for maximum performance on low-end devices.

Can I disable animations for better performance?

Yes! You can disable all animations globally:

VoidUI:ToggleAnimations(false)

You can also adjust the animation speed:

VoidUI:SetAnimationSpeed(0.5)  -- Faster animations
VoidUI:SetAnimationSpeed(2.0)  -- Slower animations
Does VoidUI cause memory leaks?

No. VoidUI is designed to prevent memory leaks through automatic cleanup:

  • Signals auto-disconnect when components are destroyed
  • The :Destroy() method cleans up all references, connections, and instances
  • Object pooling reuses instances instead of creating new ones
  • Tween callbacks are cleaned up after completion

Always call :Destroy() on windows and components when you're done with them to ensure proper cleanup.

Theming
What themes are available?

VoidUI includes 6 built-in themes:

  • Dark — the default theme with deep dark backgrounds and purple accent
  • Light — clean light theme with soft shadows
  • Midnight — ultra-dark theme with blue undertones
  • Sunset — warm theme with orange and pink accents
  • Forest — nature-inspired with green accents
  • Cyber — neon cyberpunk with vibrant colors
How do I create a custom theme?

You can create a custom theme by providing a color palette:

VoidUI:CreateTheme("MyTheme", {
    Background = Color3.fromRGB(18, 18, 28),
    Surface = Color3.fromRGB(24, 24, 38),
    SurfaceVariant = Color3.fromRGB(30, 30, 48),
    Primary = Color3.fromRGB(120, 80, 255),
    Secondary = Color3.fromRGB(100, 100, 220),
    Text = Color3.fromRGB(230, 230, 245),
    SubText = Color3.fromRGB(150, 150, 170),
    Border = Color3.fromRGB(40, 40, 60),
    Accent = Color3.fromRGB(120, 80, 255),
    Error = Color3.fromRGB(255, 90, 90),
    Warning = Color3.fromRGB(255, 180, 60),
    Success = Color3.fromRGB(40, 200, 80),
})

VoidUI:SetTheme("MyTheme")
Can I change the accent color without changing the entire theme?

Yes! You can set just the accent color while keeping the rest of the current theme:

VoidUI:SetAccent(Color3.fromRGB(0, 200, 255))

This updates the accent color across all components in real-time without requiring a full theme change.

Internationalization
What languages are supported?

VoidUI includes built-in translations for 3 languages:

  • English (en-US) — default language
  • Portuguese (pt-BR) — Brazilian Portuguese
  • Spanish (es-ES) — Castilian Spanish

Additional languages are planned for future releases.

How do I change the language?

Use the SetLanguage function:

VoidUI:SetLanguage("pt-BR")  -- Portuguese
VoidUI:SetLanguage("en-US")  -- English
VoidUI:SetLanguage("es-ES")  -- Spanish

You can also add your own translations with AddTranslations() or register a completely new language with AddLanguage().

Can I add my own translations?

Yes! You can add translations for existing languages or create entirely new ones:

-- Add translations to an existing language
VoidUI:GetI18n():AddTranslations("en-US", {
    MyButton = "Click Here",
    MyLabel = "Welcome to my app",
})

-- Add a completely new language
VoidUI:GetI18n():AddLanguage("fr-FR", {
    -- Full translation table
    MyButton = "Cliquez ici",
    -- ...
})

VoidUI:SetLanguage("fr-FR")
Plugins & Extensions
What is the Plugin System?

The Plugin System allows developers to extend VoidUI with custom components, themes, and lifecycle hooks. Plugins have access to the full VoidUI API through the plugin utilities:

  • RegisterComponent — add custom components
  • RegisterTheme — add custom themes
  • On — hook into lifecycle events (Init, BeforeCreate, AfterCreate, etc.)
  • Utils — access core utilities
  • Color — color manipulation utilities
  • Create — instance creation helper
  • Tween — animation helper
  • GetTheme — current theme access
  • Log — logging system
How do I register a plugin?

Register a plugin using the Plugin System:

local Plugin = VoidUI:GetPlugins():Register("MyPlugin")

Plugin:On("Init", function()
    Plugin:Log("MyPlugin initialized!")
end)

Plugin:RegisterComponent("MyWidget", function(config)
    -- Create and return your custom component
end)

Plugin:RegisterTheme("MyTheme", { -- theme colors })
Troubleshooting
My window isn't showing up. What should I do?

Common causes for windows not appearing:

  • Make sure the library loaded successfully — check for errors in the console
  • Ensure you're running in an environment that supports CoreGui
  • Verify that CreateWindow is being called and the return value is stored
  • Check that the window's parent isn't being destroyed by other scripts
  • Try calling Window:SetVisible(true) explicitly
My theme changes aren't applying. Why?

If theme changes aren't being applied:

  • Make sure you're using a valid theme name (VoidUI:ListThemes() to check)
  • If using a custom theme, verify it was created with CreateTheme before calling SetTheme
  • Check that all required color properties are present in your custom theme
  • Ensure components were created after the theme was set, or use VoidUI:SetTheme() which updates existing components
