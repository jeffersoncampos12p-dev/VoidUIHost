Why VoidUI?

Designed from the ground up to be the most complete and elegant UI library for the Lua scripting world.

🎨

Beautiful by Default

Soft borders, rounded corners, subtle shadows, blur effects, and micro-animations create an interface that feels premium and refined.

📦

50+ Components

From basic buttons and toggles to data tables, tree views, and terminal emulators — VoidUI has every component you need.

🌙

Six Built-in Themes

Dark, Light, Midnight, Sunset, Forest, and Cyber themes ship out of the box, plus full support for custom theme creation.

⚡

Smooth Animations

Fluid transitions, ripple effects, glow effects, and hover states with object pooling for optimal performance.

🌍

Internationalization

Built-in support for English, Portuguese, and Spanish, with the ability to add any language at runtime.

🔌

Plugin System

Extend VoidUI with custom components, themes, and lifecycle hooks through the powerful plugin architecture.

💾

State Persistence

Export and import the complete application state, including themes, window positions, and component values.

🔔

Notifications & Toasts

Built-in notification system with four variants, auto-dismiss, and a compact toast mode for quick messages.

⌨️

Command Palette

A VS Code-style command palette with fuzzy search and keyboard navigation for power users.

Get Started in Seconds

Creating a full-featured interface takes just a few lines of code.

Lua 
-- Load VoidUI
local VoidUI = loadstring(game:HttpGet(URL))()

-- Create a window
local Window = VoidUI:CreateWindow({
    Title = "My Application",
    Subtitle = "Powered by VoidUI",
    Accent = Color3.fromRGB(120, 80, 255),
})

-- Add a tab and section
local Tab = Window:CreateTab("Settings", "icon")
local Section = Tab:CreateSection("Preferences")

-- Add components
Section:CreateToggle({
    Text = "Enable Animations",
    Default = true,
    Callback = function(value)
        VoidUI:ToggleAnimations(value)
    end,
})

Section:CreateButton({
    Text = "Save Settings",
    Style = "Primary",
    Callback = function()
        VoidUI:NotifySuccess("Saved!", "Settings have been saved.")
    end,
})
